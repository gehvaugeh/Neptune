# Einrichtung des MailHog SMTP
Der MailHog soll als MailSenke für bestimmte Säulen eingerichtet werden. Damit können verschiedene Prozesse in HiO die den Mailversand benötigen getestet werden. Der MailHog tritt dabei als SMTP Server mit eigenem WebUI für das Abrufen aller eingegangen Mails ein.

Folgende übergeordneten Schritte sind dafür notwendig:
1. Freischalten der IPTables und ACLs, zunächst manuell dann per Ticket an ISSI
2. Einrichten des MailHog auf dem Webserver der jeweiligen Säule als Service
3. Apache konfigurieren für die Weiterleitung auf MailHog Port
4. Einrichten der Authentifizierung innerhalb des MailHog
5. Eintragen des MailHog auf dem Appserver in der HiO Konfiguration
